- `4611_KOWAS` 폴더에서 터미널을 엽니다.
- `data/KOWAS-EPI/`에 배포 데이터가 풀려 있어야 합니다.

cd data/KOWAS-EPI
python evaluation.py backtest --model ../../submit/model.py --out ../../runs/demo_full.csv
